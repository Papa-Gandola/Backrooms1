# THE BACKROOMS — кооперативный хоррор на двоих

Атмосферный хоррор в стиле *Escape the Backrooms*: вы вдвоём проваливаетесь в Закулисье
и пробиваетесь вниз через 5 уровней. На каждом уровне — своя сущность со своим поведением
и своя головоломка, часть из которых решается только вдвоём.

Игра работает прямо в браузере (Three.js), мультиплеер — через WebSocket-сервер на Node.js.
Никаких внешних ассетов: все текстуры и звуки генерируются процедурно.

## Запуск

```bash
npm install
npm start
```

Открой `http://localhost:3000` в браузере (Chrome/Edge/Firefox, нужен нормальный ПК с WebGL).

**Как играть вдвоём:**
1. Первый игрок жмёт «СОЗДАТЬ ИГРУ» и получает 4-значный код комнаты.
2. Второй игрок вводит код и жмёт «ВОЙТИ».
3. Игра начнётся автоматически.

- **В одной локальной сети:** второй игрок открывает `http://<IP-первого-компа>:3000`.
- **Через интернет:** задеплой на любой Node-хостинг (Railway, Render, Fly.io, VPS) —
  достаточно `npm install && npm start`, порт берётся из `process.env.PORT`.
  Либо пробрось туннель: `npx localtunnel --port 3000` / cloudflared / ngrok.

> Голосовой чат (клавиша V) использует микрофон — браузеры разрешают его только на
> `localhost` или HTTPS, поэтому через туннель/хостинг он тоже заработает.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| мышь | осмотр |
| SHIFT | бег (шумно — сущности слышат!) |
| C | присесть (тихо) |
| F | фонарик |
| E | взаимодействие (подобрать / дёрнуть / держать — крутить вентиль) |
| Q | сигнал напарнику «я настоящий» |
| V | голосовой чат |
| 1–4 | менять символы на панели доступа (уровень 2) |

## Уровни и сущности

| Уровень | Сущность | Поведение | Головоломка |
|---|---|---|---|
| 0 — Жёлтые комнаты | Скиталец | идёт на звук шагов и бега | найти 3 предохранителя и вставить в щиток |
| 1 — Тёмный склад | Гончая | видит свет фонаря, слышит бег; можно прятаться в шкафчиках | дёрнуть 2 рычага в разных концах склада с разницей < 6 сек (только вдвоём) |
| 2 — Трубы | Улыбающийся | живёт в темноте, медленно ползёт к вам; луч фонаря в упор его останавливает | найти 4 таблички с символами и ввести код на панели |
| 3 — Бассейны | Кожекрад | выглядит как ваш напарник; настоящий может подать сигнал [Q] | открыть 3 вентиля (держать E) |
| 4 — Исход | Жнец | просыпается и гонится без остановки | включить 4 рубильника на бегу и добраться до лифта вдвоём |

Если сущность вас поймала — скример и возрождение у входа на уровень (прогресс сохраняется).
Выход с уровня открывается после решения головоломки, и войти в него нужно **вдвоём**.

## Технологии

- **Клиент:** Three.js (WebGL), ACES-тонмаппинг, туман, bloom, плёночное зерно и
  хроматическая аберрация (усиливаются рядом с сущностью), тени от фонарика,
  позиционный 3D-звук (WebAudio, полностью процедурный).
- **Сервер:** Node.js + ws. Генерация лабиринтов (сид общий на комнату), ИИ сущностей
  (BFS-патфайндинг, слух/зрение/реакция на свет), состояние головоломок, античит-проверки
  дистанции взаимодействий.
- **Голос:** WebRTC peer-to-peer, сигналинг через тот же WebSocket.
